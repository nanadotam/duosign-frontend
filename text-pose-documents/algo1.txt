# Complete Algorithm Design: English Text-to-ASL Gloss with LLM Fallback

## Algorithm Overview

This system converts English text to ASL gloss notation using a **fast rule-based pipeline** with **LLM fallback** for edge cases. Optimized for real-time inference.

---

## Phase 1: Linguistic Parsing & Analysis

### Input Reception
- Accept raw English string (e.g., "I am searching for a doctor")

### Deep Tokenization
Parse using spaCy English model to extract:
- **Lemma**: Base form (e.g., "searching" → "search")
- **POS**: Part of speech (Noun, Verb, Adjective, etc.)
- **Dependencies**: Subject, Object, modifiers
- **Morphology**: Singular/Plural, Tense
- **Named Entities**: Locations, Times, Persons

```python
import spacy
nlp = spacy.load("en_core_web_sm")

def parse_text(text):
    doc = nlp(text)
    return {
        'tokens': [token for token in doc],
        'lemmas': [token.lemma_ for token in doc],
        'pos': [token.pos_ for token in doc],
        'deps': [token.dep_ for token in doc],
        'morphology': [token.morph for token in doc]
    }
```

## Phase 2: Structural Normalization

### Clause Segmentation
- Break into independent clauses based on verb phrases
- Identify main vs. subordinate clauses

### Temporal & Spatial Extraction
- Extract time markers (tomorrow, yesterday, now)
- Extract location markers (here, home, school)
- These will be topicalized (moved to front)

```python
def extract_temporal_spatial(doc):
    temporal = []
    spatial = []
    
    for token in doc:
        # Time adverbs
        if token.pos_ == "ADV" and token.dep_ in ["advmod", "npadvmod"]:
            if is_temporal(token.text):  # tomorrow, yesterday, etc.
                temporal.append(token)
        # Location entities
        if token.ent_type_ == "GPE" or token.ent_type_ == "LOC":
            spatial.append(token)
    
    return temporal, spatial
```

## Phase 3: ASL Grammar Transformation

### ASL-Specific Reordering Rules

**Key ASL Grammar Principles:**
1. **Time comes first** (Temporal topicalization)
2. **Topic-Comment structure** (Known info → New info)
3. **OSV or SOV** word order (Object before Verb common)
4. **Negation at end** of clause
5. **Questions**: WH-words at end, yes/no has non-manual markers

### Reordering Algorithm

```python
def apply_asl_grammar(tokens, parsed_data):
    """
    Apply ASL grammatical reordering rules
    """
    result = []
    temporal, spatial = extract_temporal_spatial(tokens)
    
    # Step 1: Time first
    result.extend([t.lemma_.upper() for t in temporal])
    
    # Step 2: Location/Topic
    result.extend([s.lemma_.upper() for s in spatial])
    
    # Step 3: Identify S-O-V components
    subject = find_subject(tokens)
    obj = find_object(tokens)
    verb = find_verb(tokens)
    
    # Step 4: ASL word order (Topic-Subject-Object-Verb)
    if subject:
        result.append(process_pronoun(subject))
    if obj:
        result.append(process_noun(obj))
    if verb:
        result.append(process_verb(verb))
    
    # Step 5: Negation at end
    negation = find_negation(tokens)
    if negation:
        result.append("NOT")
    
    return result
```

### Detailed Component Processing

#### Subject Processing
```python
def process_pronoun(token):
    """Convert pronouns to ASL index notation"""
    pronoun_map = {
        'i': 'IX-1',      # First person
        'me': 'IX-1',
        'you': 'IX-2',     # Second person
        'he': 'IX-3',      # Third person
        'she': 'IX-3',
        'it': 'IX-3',
        'we': 'IX-1+',     # First person plural
        'they': 'IX-3+',   # Third person plural
    }
    
    lemma = token.lemma_.lower()
    return pronoun_map.get(lemma, token.lemma_.upper())
```

#### Noun Processing
```python
def process_noun(token):
    """Handle nouns with plural markers"""
    lemma = token.lemma_.upper()
    
    # Check if plural
    if token.morph.get("Number") == ["Plur"]:
        return f"{lemma}+"
    
    return lemma
```

#### Verb Processing
```python
def process_verb(token):
    """Convert verbs to base form, handle tense"""
    lemma = token.lemma_.upper()
    
    # ASL uses time markers instead of verb tense
    # So we just use base form
    
    # Special verb mappings for ASL
    verb_map = {
        'BE': 'BE',        # Keep as-is or omit
        'HAVE': 'HAVE',    # Can be translated as possession
        'DO': '',          # Often omitted (auxiliary)
    }
    
    return verb_map.get(lemma, lemma)
```

## Phase 4: Content Filtration

### Filter Non-Content Words

```python
def filter_content_words(tokens):
    """
    Keep only high-information content words
    Remove grammatical 'glue' words
    """
    KEEP_POS = {'NOUN', 'VERB', 'ADJ', 'ADV', 'NUM', 'PROPN'}
    REMOVE_POS = {'DET', 'ADP', 'AUX', 'PUNCT', 'PART', 'CONJ', 'SCONJ'}
    
    content_words = []
    
    for token in tokens:
        # Keep content words
        if token.pos_ in KEEP_POS:
            content_words.append(token)
        
        # Exception: keep some functional words
        elif token.pos_ == 'PRON':  # Keep pronouns
            content_words.append(token)
        elif token.text.lower() == 'not':  # Keep negation
            content_words.append(token)
    
    return content_words
```

### Articles & Prepositions Removal

```python
ARTICLES = {'a', 'an', 'the'}
PREPOSITIONS = {'in', 'on', 'at', 'to', 'from', 'with', 'by', 'for'}

def remove_articles_prepositions(tokens):
    """ASL typically doesn't use articles or many prepositions"""
    return [t for t in tokens 
            if t.text.lower() not in ARTICLES 
            and t.text.lower() not in PREPOSITIONS]
```

## Phase 5: Vocabulary Mapping & Confidence Scoring

### WLASL/ASL-LEX Vocabulary Check

```python
def check_vocabulary_coverage(gloss_tokens, vocab):
    """
    Check if all glosses exist in WLASL/ASL-LEX
    Return confidence score
    """
    known_count = 0
    unknown_tokens = []
    
    for token in gloss_tokens:
        if token in vocab:
            known_count += 1
        else:
            unknown_tokens.append(token)
    
    coverage = known_count / len(gloss_tokens) if gloss_tokens else 0
    
    return {
        'coverage': coverage,
        'confidence': coverage * 1.0,  # Simple confidence metric
        'unknown_tokens': unknown_tokens
    }
```

### Confidence Triggers for LLM Fallback

```python
def needs_llm_fallback(text, gloss_result, vocab_check):
    """
    Decide if LLM fallback is needed
    """
    # Trigger 1: Low vocabulary coverage
    if vocab_check['coverage'] < 0.8:
        return True, "low_vocabulary_coverage"
    
    # Trigger 2: Contains idioms
    if contains_idioms(text):
        return True, "idiomatic_expression"
    
    # Trigger 3: Complex grammar (multiple clauses, conditionals)
    if is_complex_grammar(text):
        return True, "complex_grammar"
    
    # Trigger 4: Questions (WH-questions need special handling)
    if is_question(text):
        return True, "question_structure"
    
    return False, None

def contains_idioms(text):
    """Check for common English idioms"""
    IDIOMS = [
        'raining cats and dogs',
        'piece of cake',
        'break a leg',
        'under the weather',
        # ... expand this list
    ]
    return any(idiom in text.lower() for idiom in IDIOMS)

def is_complex_grammar(text):
    """Detect complex grammatical structures"""
    doc = nlp(text)
    
    # Multiple clauses
    if len(list(doc.sents)) > 2:
        return True
    
    # Conditional markers
    if any(token.text.lower() in ['if', 'unless', 'when'] for token in doc):
        return True
    
    return False

def is_question(text):
    """Detect questions"""
    return text.strip().endswith('?') or \
           text.lower().startswith(('what', 'when', 'where', 'who', 'why', 'how'))
```

## Phase 6: LLM Fallback Layer

### LLM Prompt Engineering

```python
def build_llm_prompt(text, rule_based_result, vocab):
    """
    Construct optimized prompt for LLM gloss conversion
    """
    
    vocab_sample = list(vocab.keys())[:100]  # Show sample of available vocab
    
    prompt = f"""You are an expert ASL (American Sign Language) linguist. Convert English text to ASL gloss notation.

ASL GRAMMAR RULES:
1. Time expressions come FIRST (TOMORROW, YESTERDAY, NOW)
2. Topic comes before comment
3. Typical word order: (TIME) (TOPIC) SUBJECT OBJECT VERB
4. Negation comes at END (NOT)
5. Questions: WH-words (WHAT, WHERE, WHO) at END
6. Use UPPERCASE for all glosses
7. Pronouns: IX-1 (I/me), IX-2 (you), IX-3 (he/she/it)
8. Plurals: Add + (CAT+ for "cats")
9. NO articles (a, an, the)
10. NO prepositions unless necessary for meaning

AVAILABLE VOCABULARY (use ONLY these signs if possible):
{', '.join(vocab_sample[:50])}
... and {len(vocab) - 50} more

EXAMPLES:
Input: "I am searching for a doctor"
Output: IX-1 DOCTOR SEARCH

Input: "The cats are sleeping on the bed"
Output: CAT+ BED SLEEP

Input: "Tomorrow I will go to school"
Output: TOMORROW IX-1 SCHOOL GO

Input: "She doesn't like pizza"
Output: IX-3 PIZZA LIKE NOT

Input: "Where is the bathroom?"
Output: BATHROOM WHERE

"""
    
    # Include rule-based attempt if available
    if rule_based_result:
        prompt += f"""
RULE-BASED ATTEMPT:
{' '.join(rule_based_result)}

Please review and provide a better ASL gloss if needed.
"""
    
    prompt += f"""
INPUT: "{text}"
OUTPUT (ASL gloss only, no explanation):"""
    
    return prompt

def llm_convert(text, rule_based_result, vocab, llm_client):
    """
    Call LLM for gloss conversion
    """
    prompt = build_llm_prompt(text, rule_based_result, vocab)
    
    # Call LLM (using Claude API as example)
    response = llm_client.complete(
        prompt=prompt,
        max_tokens=100,
        temperature=0.3  # Low temp for consistency
    )
    
    # Parse response (remove any extra text)
    gloss = response.strip().upper()
    gloss_tokens = gloss.split()
    
    return gloss_tokens
```

## Phase 7: Synthesis & Output

### Final Assembly

```python
def finalize_gloss(gloss_tokens):
    """
    Final formatting and validation
    """
    # Remove empty strings
    gloss_tokens = [t for t in gloss_tokens if t]
    
    # Ensure uppercase
    gloss_tokens = [t.upper() for t in gloss_tokens]
    
    # Join with spaces
    final_gloss = ' '.join(gloss_tokens)
    
    return final_gloss
```

## Complete Algorithm Implementation

```python
class EnglishToASLGloss:
    def __init__(self, wlasl_vocab, asl_lex_vocab, llm_client=None):
        self.nlp = spacy.load("en_core_web_sm")
        self.wlasl_vocab = wlasl_vocab
        self.asl_lex_vocab = asl_lex_vocab
        self.llm = llm_client
        self.cache = {}
        
        # Combine vocabularies
        self.vocab = set(wlasl_vocab.keys()) | set(asl_lex_vocab.keys())
        
        # Metrics
        self.metrics = {
            'rule_based': 0,
            'llm_fallback': 0,
            'cache_hits': 0
        }
    
    def convert(self, text):
        """
        Main conversion pipeline
        """
        # Check cache first
        if text in self.cache:
            self.metrics['cache_hits'] += 1
            return self.cache[text]
        
        # PHASE 1: Parse
        doc = self.nlp(text)
        
        # PHASE 2-4: Rule-based conversion
        gloss_tokens = self._rule_based_convert(doc)
        
        # PHASE 5: Check confidence
        vocab_check = self._check_vocabulary(gloss_tokens)
        needs_fallback, reason = needs_llm_fallback(text, gloss_tokens, vocab_check)
        
        # PHASE 6: LLM fallback if needed
        if needs_fallback and self.llm:
            print(f"[LLM Fallback] Reason: {reason}")
            gloss_tokens = llm_convert(text, gloss_tokens, self.vocab, self.llm)
            self.metrics['llm_fallback'] += 1
        else:
            self.metrics['rule_based'] += 1
        
        # PHASE 7: Finalize
        final_gloss = finalize_gloss(gloss_tokens)
        
        # Cache result
        self.cache[text] = final_gloss
        
        return final_gloss
    
    def _rule_based_convert(self, doc):
        """
        Apply all rule-based transformations
        """
        # Extract temporal/spatial markers
        temporal, spatial = extract_temporal_spatial(doc)
        
        # Filter content words
        content_tokens = filter_content_words(doc)
        content_tokens = remove_articles_prepositions(content_tokens)
        
        # Apply ASL grammar
        gloss_tokens = apply_asl_grammar(content_tokens, doc)
        
        return gloss_tokens
    
    def _check_vocabulary(self, gloss_tokens):
        """Check vocabulary coverage"""
        return check_vocabulary_coverage(gloss_tokens, self.vocab)
    
    def get_metrics(self):
        """Return usage statistics"""
        return self.metrics
```


```
  Tokens: [I, am, searching, for, a, doctor]

  Coverage: 100% (all in WLASL)
```

## Performance Characteristics

### Speed Targets
- **Rule-Based Path**: <50ms per sentence
- **LLM Fallback**: 500-2000ms per sentence
- **Cache Hit**: <1ms

### Expected Distribution
- **Rule-Based**: 75-85% of queries
- **LLM Fallback**: 15-25% of queries
- **Cache Hits**: 30-40% after warmup

### Optimization Tips
1. **Preload spaCy model** at startup
2. **Batch LLM calls** if processing multiple sentences
3. **Warm cache** with common phrases
4. **Monitor fallback rate** - if >30%, improve rules
