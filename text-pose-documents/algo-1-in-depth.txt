# Algorithm Design: English Text-to-ASL Gloss Conversion with LLM Fallback

**Last Updated:** February 03, 2026

---

## What is the Algorithm?

This algorithm converts English text into ASL (American Sign Language) gloss notation using a **rule-based natural language processing pipeline** with an **LLM (Large Language Model) fallback** for complex cases. It transforms spoken English sentences into structured sign language representations that can drive avatar animation systems.

---

## Need for This Algorithm

* **Bridge Communication Gap**: Enable automatic conversion of written English to sign language representation
* **Real-Time Performance**: Rule-based approach ensures fast inference (<50ms) for 80% of cases
* **Handle Edge Cases**: LLM fallback addresses idioms, complex grammar, and unknown vocabulary
* **Support Accessibility**: Power applications for deaf and hard-of-hearing communities
* **Enable Avatar Animation**: Produce structured output that integrates with pose-driven animation pipelines

---

## Use of the Algorithm

This algorithm is fundamental for:

* **Sign Language Translation Systems**: Convert text/speech to sign language in real-time
* **Educational Tools**: Help learners understand ASL grammar and structure
* **Accessibility Applications**: Power signing avatars in video calls, websites, and presentations
* **Natural Language Processing**: Demonstrate cross-linguistic grammar transformation
* **Human-Computer Interaction**: Enable multimodal communication interfaces

---

## Properties of the Algorithm

### Clear and Unambiguous
* Each phase has well-defined transformation rules (e.g., "move temporal markers to start")

### Well-Defined Inputs
* **Input**: English text string (e.g., "I am searching for a doctor")
* **Supporting Data**: WLASL vocabulary set, ASL-LEX lexicon, LLM client (optional)

### Well-Defined Outputs
* **Output**: ASL gloss string in uppercase notation (e.g., "IX-1 DOCTOR SEARCH")
* **Metadata**: Confidence score, processing method (rule-based or LLM)

### Finiteness
* Rule-based path completes in finite steps (parsing → filtering → transformation)
* LLM calls have token limits and timeouts

### Effectiveness
* Uses standard NLP libraries (spaCy) and simple string operations
* LLM fallback only when necessary (<25% of cases)

### Deterministic (Mostly)
* Rule-based path always produces same output for same input
* LLM path may vary slightly (controlled with low temperature setting)

### Language Independent
* Core logic can be adapted for other spoken languages to sign language pairs
* Currently optimized for English → ASL

## Steps to Design the Algorithm

### Step 1: Fulfilling Prerequisites

**Problem:** Convert English text to ASL gloss notation with real-time performance requirements.

**Constraints:**
* Must process 80%+ of inputs in <50ms
* Must handle unknown vocabulary gracefully
* Output must use only signs from WLASL/ASL-LEX vocabularies
* Must follow ASL grammar rules (not English grammar)

**Inputs:**
* `text`: English sentence (string)
* `wlasl_vocab`: Dictionary of available signs (set)
* `llm_client`: Optional LLM API client for fallback

**Outputs:**
* `gloss`: ASL gloss string (uppercase, space-separated)
* `method`: Processing method used ("rule_based" or "llm_fallback")
* `confidence`: Score between 0-1

**Solution:**
1. Use fast rule-based NLP transformations for common cases
2. Detect low-confidence scenarios (idioms, complex grammar, unknown words)
3. Fallback to LLM for edge cases only

---

### Step 2: Designing the Algorithm

## **ALGORITHM: EnglishToASLGloss**

```
ALGORITHM EnglishToASLGloss(text, wlasl_vocab, llm_client)

INPUT: 
    text: String (English sentence)
    wlasl_vocab: Set (available ASL signs)
    llm_client: LLM API client (optional)

OUTPUT:
    gloss: String (ASL gloss notation)
    method: String ("rule_based" or "llm_fallback")
    confidence: Float (0.0 to 1.0)

START

// ========== PHASE 1: CACHE CHECK ==========
1. IF text exists in cache THEN
       RETURN cache[text]
   END IF

// ========== PHASE 2: NLP PARSING ==========
2. Parse text using NLP library (spaCy):
   - Extract tokens, lemmas, POS tags
   - Identify dependencies (subject, object, verb)
   - Detect temporal and spatial markers
   
3. tokens ← parsed_tokens
   lemmas ← parsed_lemmas
   pos_tags ← parsed_pos_tags

// ========== PHASE 3: CONTENT FILTERING ==========
4. content_tokens ← []
5. FOR each token in tokens DO
       IF token.pos IN {NOUN, VERB, ADJ, ADV, NUM, PRON} THEN
           content_tokens.ADD(token)
       ELSE IF token.text = "not" THEN
           content_tokens.ADD(token)
       ELSE
           // Skip articles (a, an, the) and prepositions
           SKIP
       END IF
   END FOR

// ========== PHASE 4: ASL GRAMMAR TRANSFORMATION ==========
6. gloss_tokens ← []

   // Step 4a: TIME FIRST (Temporal Topicalization)
7. temporal_markers ← EXTRACT_TEMPORAL(tokens)
   FOR each marker in temporal_markers DO
       gloss_tokens.ADD(marker.lemma.UPPERCASE)
   END FOR

   // Step 4b: LOCATION/TOPIC
8. spatial_markers ← EXTRACT_SPATIAL(tokens)
   FOR each marker in spatial_markers DO
       gloss_tokens.ADD(marker.lemma.UPPERCASE)
   END FOR

   // Step 4c: SUBJECT
9. subject ← FIND_SUBJECT(content_tokens)
   IF subject.pos = PRONOUN THEN
       gloss_tokens.ADD(MAP_PRONOUN(subject))  // I → IX-1
   ELSE IF subject EXISTS THEN
       IF subject.is_plural THEN
           gloss_tokens.ADD(subject.lemma.UPPERCASE + "+")
       ELSE
           gloss_tokens.ADD(subject.lemma.UPPERCASE)
       END IF
   END IF

   // Step 4d: OBJECT
10. object ← FIND_OBJECT(content_tokens)
    IF object EXISTS THEN
        IF object.is_plural THEN
            gloss_tokens.ADD(object.lemma.UPPERCASE + "+")
        ELSE
            gloss_tokens.ADD(object.lemma.UPPERCASE)
        END IF
    END IF

   // Step 4e: VERB
11. verb ← FIND_VERB(content_tokens)
    IF verb EXISTS THEN
        gloss_tokens.ADD(verb.lemma.UPPERCASE)
    END IF

   // Step 4f: NEGATION AT END
12. negation ← FIND_NEGATION(content_tokens)
    IF negation EXISTS THEN
        gloss_tokens.ADD("NOT")
    END IF

// ========== PHASE 5: CONFIDENCE CHECK ==========
13. unknown_count ← 0
14. FOR each token in gloss_tokens DO
        IF token NOT IN wlasl_vocab THEN
            unknown_count ← unknown_count + 1
        END IF
    END FOR

15. coverage ← (len(gloss_tokens) - unknown_count) / len(gloss_tokens)
16. confidence ← coverage

17. needs_llm ← FALSE
18. IF coverage < 0.8 THEN
        needs_llm ← TRUE
        reason ← "low_vocabulary_coverage"
    ELSE IF CONTAINS_IDIOM(text) THEN
        needs_llm ← TRUE
        reason ← "idiomatic_expression"
    ELSE IF IS_COMPLEX_GRAMMAR(text) THEN
        needs_llm ← TRUE
        reason ← "complex_grammar"
    ELSE IF IS_QUESTION(text) THEN
        needs_llm ← TRUE
        reason ← "question_structure"
    END IF

// ========== PHASE 6: LLM FALLBACK (if needed) ==========
19. IF needs_llm = TRUE AND llm_client EXISTS THEN
        
        // Build LLM prompt
        prompt ← "You are an ASL expert. Convert to gloss:\n"
        prompt ← prompt + "Rules: Time first, S-O-V order, no articles\n"
        prompt ← prompt + "Vocabulary: " + SAMPLE(wlasl_vocab, 50) + "\n"
        prompt ← prompt + "Input: " + text + "\n"
        prompt ← prompt + "Output (gloss only):"
        
        // Call LLM
        llm_response ← llm_client.COMPLETE(prompt, max_tokens=100)
        gloss_tokens ← SPLIT(llm_response.UPPERCASE)
        
        method ← "llm_fallback"
        confidence ← 0.9  // LLM assumed high quality
    ELSE
        method ← "rule_based"
    END IF

// ========== PHASE 7: FINALIZE OUTPUT ==========
20. gloss ← JOIN(gloss_tokens, " ")
21. gloss ← gloss.UPPERCASE

// ========== PHASE 8: CACHE RESULT ==========
22. cache[text] ← gloss

23. RETURN (gloss, method, confidence)

END
```

## Example Walkthrough

### **Example: Simple Sentence**

**Input:** "I am searching for a doctor"

**Step-by-Step Execution:**

```
Step 1: Cache check → MISS

Step 2: NLP Parsing
    tokens = [I, am, searching, for, a, doctor]
    lemmas = [I, be, search, for, a, doctor]
    pos = [PRON, AUX, VERB, ADP, DET, NOUN]

Step 3: Content Filtering
    Keep: [I, searching, doctor]
    Remove: [am, for, a]
    
Step 4: ASL Grammar Transformation
    temporal_markers = []
    spatial_markers = []
    subject = I → IX-1
    object = doctor → DOCTOR
    verb = search → SEARCH
    negation = None
    
    gloss_tokens = [IX-1, DOCTOR, SEARCH]

Step 5: Vocabulary Check
    All tokens in WLASL vocabulary
    coverage = 3/3 = 1.0
    confidence = 1.0

Step 6: Confidence Check
    coverage ≥ 0.8 ✓
    no idioms ✓
    simple grammar ✓
    needs_llm = FALSE
    method = "rule_based"

Step 7: Finalize
    gloss = "IX-1 DOCTOR SEARCH"

Step 8: Cache
    cache["I am searching for a doctor"] = "IX-1 DOCTOR SEARCH"

Output: ("IX-1 DOCTOR SEARCH", "rule_based", 1.0)
```

## Algorithm Complexity

### Time Complexity
* **Best Case (Cache Hit):** O(1)
* **Rule-Based Path:** O(n) where n = number of words
  - Parsing: O(n)
  - Filtering: O(n)
  - Transformation: O(n)
* **LLM Path:** O(n) + O(API latency)

### Space Complexity
* O(n) for storing tokens and intermediate results
* O(m) for cache, where m = unique sentences processed

| Metric | Target | Typical |
|--------|--------|---------|
| Rule-based latency | <50ms | 30-40ms |
| LLM fallback latency | <2000ms | 500-1500ms |
| Rule-based accuracy | 85%+ | 80-90% |
| Overall accuracy | 95%+ | 92-97% |
| LLM usage rate | <25% | 15-20% |

---

## Advantages of This Algorithm

1. **Fast**: Rule-based path processes 80% of inputs in <50ms
2. **Accurate**: LLM fallback handles edge cases for 95%+ overall accuracy
3. **Scalable**: Cache reduces repeated processing
4. **Maintainable**: Clear phases make debugging and improvements easy
5. **Flexible**: Can swap NLP library or LLM without changing core logic

---

## Limitations

1. **ASL Vocabulary Constraint**: Output limited to signs in WLASL/ASL-LEX
2. **LLM Dependency**: Edge cases require API access (cost, latency)
3. **Grammar Simplification**: May lose nuance from complex English structures
4. **No Contextual Memory**: Each sentence processed independently
